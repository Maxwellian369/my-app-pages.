n8n

Purpose of this application: This is a personal, self-hosted instance of n8n used to create automated workflows. It connects to Google Drive to allow for the automated management of files and documents, such as reading, writing, and organizing data as part of a user-defined automation sequence.

How We Use Google Data

Access to Google Drive is requested solely to perform the automation tasks configured by the user. The data is used only for the functionality of the n8n workflow and is not stored or shared externally.

For more details, please read our Privacy Policy.
